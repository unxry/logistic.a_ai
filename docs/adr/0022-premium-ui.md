# ADR-0022: Премиальный UI (Stage 9) — дизайн-система, shell, qasync

- **Статус:** Принято
- **Дата:** 2026-07-31

## Контекст

Headless-платформа готова (этапы 0–8.6), контракты данных зафиксированы
снапшотами. Нужен интерфейс уровня коммерческого macOS-приложения
(ориентиры: Apple Intelligence, Linear, Raycast), который останется тонким:
вся логика — за ViewModel'ями Stage 8.6.

## Решение

1. **Дизайн-система прежде кода**: `docs/design-system.md` (цвета из ТЗ:
   #F5F5F7 / #30D158 / #FF9F0A / #FF453A / #0A84FF; типографика, сетка 4pt,
   радиусы, три уровня теней, motion-паттерны) и её код-зеркало
   `app/ui/theme/tokens.py` — синхронизация охраняется тестом. Прямых hex в
   виджетах нет.
2. **«Стекло» через QSS-токены** (полупрозрачный белый + мягкая тень + тонкая
   граница): нативный NSVisualEffectView подключится при упаковке (ADR-0002)
   без смены токенов. Тени — QGraphicsDropShadowEffect (RESTING/LIFTED/GLOW).
3. **Motion-паттерны** (`theme/motion.py`): materialize (fade + рост 0.96→1
   через поля обёртки — layout не прыгает), count-up, lift теней, пульс
   статуса. Анимации прерываемы (guard shiboken6.isValid + остановка
   предыдущей), таймеры парентованы виджетам — никаких «выстрелов» по
   удалённым объектам.
4. **Библиотека компонентов** (`app/ui/widgets`): Button (4 вида), Badge,
   StatusIndicator (пульс), SkeletonBlock, GlassCard/HoverCard, MetricCard,
   Sparkline, ScoreRing (glow, пороги цвета), Timeline, Modal, Toast/ToastHost,
   CommandPalette (⌘K), Sidebar, EmptyState/ErrorState, FlowLayout (чипы и
   бейджи переносятся, а не распирают карточки), HeroCard, CargoCardWidget,
   SourceRow. Каждый — переиспользуемый, на токенах.
5. **Shell** (`main_window.py`): сайдбар-стекло (7 разделов) + QStackedWidget
   страниц + статус-бар (статус приложения + Telegram) + тосты + модалка
   AI Explanation + палитра команд + шорткаты (⌘K/⌘R/⌘1…7). Данные приходят
   ТОЛЬКО через `UiEventBridge` (три UI-события → Qt-сигналы) и снапшоты.
6. **qasync** (ADR-0003 исполнен): одна петля asyncio+Qt, стартовый
   `dashboard.refresh()` задачей, выход по aboutToQuit.
7. **Demo-режим** (`--demo` / LOGISTAI_DEMO=1): дашборд живёт на
   MockDashboardDataProvider с замороженными часами; через 1.2 с после
   старта «AI находит» лучший груз — hero материализуется, деньги набегают,
   приходит тост. Продукт можно смотреть и снимать без живых источников.

## Сознательно отложено (этап 9.1)

- Формы настроек (токен/Chat ID/проверка, тарифы маршрутов) — команды и
  Keychain готовы, нужен только UI форм.
- Реальные почасовые ряды для Sparkline (сейчас график в демо; в живом
  режиме метрики без графика — честно).
- Drag-and-drop: в текущем продукте нет сценария перетаскивания (нечего и
  некуда); появится вместе с управлением списками (закладки грузов).
- Коалесинг UI-событий (debounce) — при живом потоке источников.

## Последствия

(+) UI — тонкий слой: ни одного импорта services/infrastructure из ui
(контракты import-linter 7/7); дизайн не расползётся — токены и золотые
снапшоты охраняются тестами; демо-режим продаёт продукт без бэкенда.
(−) Эмодзи-глифы сайдбара зависят от системного шрифта (на macOS — ок);
«стекло» до упаковки — эмуляция; тесты UI покрывают поведение, пиксельная
регрессия — вне скоупа.
