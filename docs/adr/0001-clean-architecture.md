# ADR-0001: Clean Architecture + Ports & Adapters

- **Статус:** Принято
- **Дата:** 2026-07-31

## Контекст

Коммерческое desktop-приложение с длинным жизненным циклом: v0.1 — инфраструктура,
дальше мониторинг источников (ATI и др.), аналитика, AI. Обязательное требование —
Windows-порт без переписывания логики. Команда может вырасти; проект — до сотен файлов.

## Решение

Слои с правилом зависимостей «стрелки только внутрь»: `ui → services → core ←
infrastructure`. Ядро (`app/core`) — чистый Python: модели, события, команды,
порты (`typing.Protocol`), ошибки. Инфраструктура реализует порты; сборка — в
composition root (`bootstrap.py`). Правило охраняется import-linter в CI.

## Альтернативы

- **MVC-монолит на Qt** — быстрее старт, но UI срастается с логикой, порт и тесты дорожают.
- **Папки по фичам без слоёв** — приемлемо для маленьких утилит; при росте зависимостей
  превращается в клубок, направление импортов не контролируется.

## Последствия

(+) Логика тестируется без GUI и сети; Windows-порт = замена 3–4 адаптеров;
новые модули (monitor, analytics) не ломают структуру.
(−) Больше файлов и церемоний: порты, адаптеры, DI. Компенсируется рецептами
в ARCHITECTURE.md и автоматической проверкой контрактов.
