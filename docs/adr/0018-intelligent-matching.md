# ADR-0018: Intelligent Matching v1 (предпочтения, прибыль, объяснимость)

- **Статус:** Принято
- **Дата:** 2026-07-31

## Контекст

Search Engine отвечает «что подходит машине»; нужен слой «что выгодно и
приятно ЭТОМУ водителю» — с объяснением причин. Без ML и внешних AI —
детерминированные правила + фундамент для будущего обучения.

## Решение

1. **DriverProfile** — доменная модель предпочтений (регионы ±, категории,
   кузова, минимальная ставка/прибыль, комфортное плечо, домашний регион) —
   отдельно от VehicleProfile (машина ≠ водитель).
2. **MatchingContext** (машина + водитель + текущая локация + время) —
   один объект во все расчёты.
3. **PreferenceEngine**: база 50; +20 любимый регион, +15 категория, +10 кузов,
   +10 комфортное плечо, −30 ставка ниже минимума; запрещённый регион —
   жёсткий отказ (событие CargoRejectedByPreference).
4. **CargoProfitCalculator** (Decimal): расходы = (плечо + холостой) ×
   (топливо 35 + дорожные 15 ₽/км, инжектируемые ProfitAssumptions) →
   ProfitEstimate(revenue/expenses/profit/profit_per_km). Пример ТЗ
   зафиксирован тестом: 120 000 − 35 000 = 85 000 ₽.
5. **RouteScoreCalculator v1** без карт: загрузка в домашнем регионе +50
   («минимальный холостой пробег»), рядом с текущей локацией +40, выгрузка
   домой +10. Порт **RouteProvider** заготовлен (Google/Яндекс/OSRM) — точные
   расстояния придут без изменения калькулятора.
6. **final_score** = 40% совместимость + 25% прибыль + 20% предпочтения +
   15% маршрут (MatchingWeights — инжектируются, не хардкод); tie-break —
   большая прибыль. **IntelligentCargoMatch.explanation** — человекочитаемые
   причины («Идеальная совместимость», «Прибыль 85 000 ₽», «Ваше направление»,
   «Минимальный холостой пробег»).
7. **Learning-фундамент**: каждое решение — MatchingDecision (cargo, driver,
   score, selected/rejected_reason, trace_id) + событие MatchingDecisionCreated;
   выбор лучшего — BestCargoSelected; уведомление «🚚 Лучший груз найден»
   с «Почему: ✅…» через Notification Center.

## Последствия

(+) Выбор объясним (готово для UI и доверия пользователя); каждый калькулятор
заменяем; решения копятся для Stage 8 (аналитика) и будущего обучения весов.
(−) Допущения v1 (50 ₽/км, эталон прибыли 120 ₽/км, фиксированный холостой
50 км вне домашнего региона) — калибруются на живых данных; хранение решений
в памяти — Stage 8 перенесёт в SQLite.
