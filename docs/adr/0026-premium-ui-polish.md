# ADR-0026: Премиальный полиш UI — двойная тема и living-motion

- **Статус:** Принято
- **Дата:** 2026-08-01

## Контекст

Stage 9 дал дизайн-систему и рабочий shell; Stage 9.8 поднимает качество до
уровня коммерческого macOS-приложения (ориентиры: Apple, Linear, Raycast,
Craft, Things 3). Ограничения: только UI/UX — архитектура, домен, ViewModel'и,
сервисы, Scheduler и Telegram не меняются; производительность не деградирует;
анимации невидимых виджетов не работают.

## Решение

1. **Двойная тема как данные, не как ветвления.** В `tokens.py` появились две
   ПОЛНОЦЕННЫЕ палитры `LIGHT`/`DARK` (`ThemePalette`): поверхности, текст,
   скелетоны и глубина тени заданы отдельно (Dark — графит Sonoma `#161618`,
   карточки светлее фона, тени ×1.8, акценты Apple общие).
   `tokens.apply_theme(theme)` мутирует модульные токены и вызывается
   composition root'ом из `settings.ui.theme` ДО сборки окна — QSS всех
   виджетов собирается при конструировании и получает тему автоматически.
   Модульные QSS-константы, зависевшие от темы (кнопки, пункты сайдбара),
   превращены в функции — порядок импорта не влияет. Живое переключение без
   пересборки окна и режим System — вместе с формами настроек (Stage 9.1).
2. **Глубина: три состояния поверхности.** `SHADOW_RESTING` (покой) →
   `SHADOW_LIFTED` (hover) → `SHADOW_ACTIVE` (нажатие «прижимает» карточку);
   hover дополнительно подсвечивает фон `CARD → CARD_HOVER` и рамку. Геометрия
   карточек НИКОГДА не анимируется — ничего не прыгает и не двигает layout.
3. **Motion-паттерны 9.8** (`theme/motion.py`): `cascade` — каскад секций со
   сдвигом 30–60 мс (одна волна, один таймлайн ощущений); `enter_page` — fade +
   «подъезд» контента на 12 px через поля layout'а; `breathing` — НЕзапущенный
   бесконечный цикл 0→1→0 (владелец обязан стартовать/останавливать его в
   show/hideEvent — правило «скрытый виджет не жжёт кадры» закреплено тестами);
   `reveal_scrollbar_on_scroll` — скроллбар-невидимка через динамическое
   свойство `revealed` + linger-таймер (стиль читает глобальный QSS).
4. **Сайдбар.** Световой градиент-стекло (`SIDEBAR_TOP→SIDEBAR_BOTTOM` +
   верхний блик), статус-пилюля приложения сверху, футер-карточка с версией и
   бейджами Telegram/ATI/Планировщик. Активный пункт — плавающая капсула,
   скользящая между пунктами (QVariantAnimation по QRect, OutCubic, BASE);
   при пересчёте layout'а капсула «доснимается» в show/resizeEvent. Новые
   данные приходят из окна методом `set_link_tones(...)` — тоны из snapshot
   viewmodel'ей, MVVM не нарушен.
5. **Живые окончания графиков.** ScoreRing — светящаяся точка на конце дуги
   (позиция из угла прогресса), пульсирует как Apple Activity Rings; Sparkline
   отрисовывается анимацией слева направо (клип по доле) и дышит конечной
   точкой; идентичный ряд не перезапускает отрисовку. Оба цикла останавливаются
   у скрытых виджетов.
6. **AI Explanation — macOS sheet.** Modal позиционируется у верхней кромки и
   выезжает сверху (26 px + fade). Содержимое собирает
   `widgets/cargo.build_explanation_panel`: каждая причина — стеклянная
   мини-карточка с иконкой по смыслу (📈 🛣 💰 🚚 ✔, презентационная эвристика
   по тексту причины), футер-итог: AI Score · Совместимость · Прибыль ·
   Маршрут. Окно тонкое: строит панель одной функцией.
7. **Палитра ⌘K в духе Raycast.** Строки — виджеты с иконкой, заголовком с
   подсветкой совпадения (HTML экранируется) и хоткеем-капсулой справа;
   безрамочный крупный поиск с разделителем; открытие — scale 0.98→1 + fade.
   `Command` расширен полем `icon` (совместимо, default "").
8. **Пустые состояния и скелетоны.** `IllustrationBadge` — глиф в двух мягких
   кругах тона (минимальная иллюстрация); скелетон берёт базу из палитры
   (тёмная тема — светлые альфы).

## Альтернативы

- **Живое переключение темы** (repolish всех виджетов на лету) — отклонено
  сейчас: без форм настроек (9.1) переключать нечем; мутация токенов до сборки
  окна покрывает запуск из настроек и не требует ни одного изменения в
  виджетах.
- **QGraphicsView/QML для scale-анимаций карточек** — отклонено: тяжёлый
  relayout и размытие текста; масштаб имитируется полями (materialize) и
  светом (hover), геометрия не трогается.
- **Нативный NSVisualEffectView для блюра** — остаётся планом этапа упаковки
  (ADR-0002): QSS-стекло уже даёт нужный характер, токены не изменятся.

## Последствия

(+) Обе темы — полноценные палитры уровня Sonoma, покрыты тестами
(палитры различаются по всем полям, фон не чёрный, тени упорядочены,
док-синхронизация); 403 теста, mypy strict, контракты import-linter 7/7.
(+) Все бесконечные анимации подчиняются правилу видимости (тесты пульса).
(−) Иконки-эмодзи зависят от платформенного шрифта (на macOS — штатно);
(−) System-тема и live-switch отложены до Stage 9.1 (composition root уже
готов: `apply_theme` — единственная точка).
