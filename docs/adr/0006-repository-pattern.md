# ADR-0006: Repository Pattern для хранилищ

- **Статус:** Принято
- **Дата:** 2026-07-31

## Контекст

Хранилища будут меняться: JSON-настройки, SQLite-журнал сейчас; SQLAlchemy или
иная БД — возможно, позже (домен грузов). Сервисы не должны знать деталей хранения.

## Решение

Порты-репозитории в ядре (`SettingsRepository`, `HistoryRepository`, …) +
реализации в `infrastructure` (`JsonSettingsRepository`,
`SqliteHistoryRepository`). Сырой SQL — только внутри `infrastructure/storage`.

## Альтернативы

- **Активные записи / прямые вызовы SQL из сервисов** — быстро, но хранилище
  прорастает в логику, тесты требуют реальной БД.
- **Сразу SQLAlchemy ORM** — лишняя зависимость для v0.1 (см. ADR-0007).

## Последствия

(+) Сервисы тестируются фейками портов; смена хранилища — локальная замена адаптера.
(−) Немного дублирования сигнатур порт/реализация — цена изоляции.
