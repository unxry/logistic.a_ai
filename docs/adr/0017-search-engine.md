# ADR-0017: Search Engine, стратегия подбора и модель скоринга

- **Статус:** Принято
- **Дата:** 2026-07-31

## Контекст

Главная ценность продукта: «мой автомобиль → только подходящие заказы →
оценить → отсортировать лучшие». Все кирпичи готовы (совместимость,
источники, NC, Scheduler) — нужен headless-движок подбора.

## Решение

**Пайплайн из заменяемых шагов** (каждый — класс с одной ответственностью,
инжектится в движок):

1. `CargoPreFilter` — дешёвый отсев по критериям запроса (категория, регион,
   вес, наличие цены при min_price, дистанция). Совместимость НЕ решает;
   отсутствие данных не отбрасывает.
2. `CargoCompatibilityService` — существующий (ADR-0009), новой логики
   размеров нет.
3. `CargoScoreCalculator` — балл 0–100: 40% совместимость, 20% ставка
   (руб/км против эталона 150, Decimal для денег), 20% плечо (короче — выше),
   10% свежесть (сутки → 0), 10% категория. Несовместимый груз — всегда 0.
   Веса — `ScoringWeights` (заменяемы); эвристики v1 зафиксированы тестами,
   Stage 9 заменит компонент цены на настоящую экономику рейса.
4. `CargoRankingService` — совместимые первыми → score ↓ → цена ↓ → свежие
   первыми; позиции 1..N.

**Модели**: `CargoSearchQuery` (пустой критерий = «без ограничений»),
`CargoMatch` (cargo + CompatibilityResult + score + estimated_profit —
заполнит Stage 9), `SearchResult` (best, compatible_matches).
`Cargo.created_at` добавлен — момент получения из источника (нужен свежести
и ранжированию; найден именно на этом этапе).

**Слои**: `CargoSearchEngine` — чистый (ни ATI, ни Telegram, ни SQLite, ни
UI, sync); `CargoMatchingService` — оркестрация: кандидаты из порта
`CargoRepository` (InMemory сейчас, SQLite позже), события
CargoMatched/CargoRejected/SearchCompleted (trace_id насквозь), уведомление
о лучшем грузе через NC (категория CARGO, кнопка «Открыть» с URL груза).

## Последствия

(+) Скоринг/совместимость/хранилище заменяемы по отдельности; e2e-тест
доказывает цепочку RawCargo → Normalizer → Engine → Match → NC.
(−) Эвристики скоринга v1 (эталонная ставка, окно свежести) — калибруются
на живых данных ATI; события CargoMatched/Rejected на каждый груз шумны при
тысячах карточек — Stage 8 добавит агрегирование.
