# ADR-0007: SQLite через stdlib sqlite3

- **Статус:** Принято
- **Дата:** 2026-07-31

## Контекст

Локальное однопользовательское desktop-приложение. В v0.1 хранится журнал
событий; в будущем — кэш грузов, рейтинги, аналитика.

## Решение

SQLite (файл в Application Support), stdlib `sqlite3`, WAL-режим, таблица
миграций + SQL-файлы. Вызовы из async-кода — через `asyncio.to_thread` внутри
репозитория. SQLAlchemy отложен до появления домена грузов — благодаря
Repository Pattern (ADR-0006) миграция будет локальной.

## Альтернативы

- **JSON-файлы** — нет запросов/индексов, журнал быстро деградирует.
- **Клиент-серверная БД (Postgres)** — администрирование, лишнее для локального ПО.
- **SQLAlchemy сразу** — зависимость и слой абстракции без текущей необходимости.

## Последствия

(+) Ноль администрирования, транзакции, один файл, отличная производительность чтения.
(−) sqlite3 синхронный — обёртка to_thread; ORM-удобств нет, схема руками
(осознанно до v0.2+).
