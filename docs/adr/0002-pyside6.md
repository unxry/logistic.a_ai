# ADR-0002: PySide6 как GUI-фреймворк

- **Статус:** Принято
- **Дата:** 2026-07-31

## Контекст

Нужен современный нативно выглядящий UI на macOS (тёмная тема, glassmorphism,
анимации), Python-стек, будущий Windows-порт, закрытая коммерческая лицензия продукта.

## Решение

PySide6 (Qt for Python, официальная привязка от Qt Company, лицензия LGPL).

## Альтернативы

- **PyQt6** — функционально эквивалентен, но GPL/коммерческая лицензия; для
  закрытого ПО LGPL PySide6 удобнее.
- **Tkinter** — устаревший вид, слабая стилизация: уровень «современного macOS» недостижим.
- **Kivy / Toga** — не дают desktop-нативного поведения и зрелой экосистемы виджетов.
- **Electron/Tauri + веб** — другой язык/стек, тяжёлый рантайм, дублирование логики.

## Последствия

(+) Кроссплатформенность из коробки, зрелые виджеты, QSS-стилизация, Qt Designer не нужен.
(−) Истинная vibrancy macOS недоступна штатно — «стекло» делается токенами QSS
(осознанный компромисс, см. оговорки в архитектуре); вес зависимости ~200 МБ.
