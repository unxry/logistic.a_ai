# ADR-0008: Секреты в Keychain через keyring

- **Статус:** Принято
- **Дата:** 2026-07-31

## Контекст

Bot Token Telegram — секрет. Хранение в plain-text JSON рядом с настройками —
не коммерческий уровень: файл читается любым процессом пользователя и попадает
в бэкапы.

## Решение

Порт `SecretStore` в ядре; реализация `KeyringSecretStore` (библиотека
`keyring`): macOS Keychain сейчас, Windows Credential Manager — тем же кодом
при портировании. Фолбэк при недоступности Keychain — явно деградированный
режим с предупреждением в журнале.

## Альтернативы

- **Plain JSON** — просто, но небезопасно (см. контекст).
- **Собственное шифрование файла** — ключ всё равно негде хранить, кроме Keychain;
  изобретение велосипеда.
- **ENV-переменные** — неудобно для desktop-пользователя, секрет в профиле шелла.

## Последствия

(+) Секрет под защитой ОС; кроссплатформенность бесплатно; настройки-JSON можно
безопасно бэкапить.
(−) Первый доступ может показать системный диалог Keychain; в CI/тестах нужен
фейковый SecretStore (он и так есть по правилам тестирования).

> Stage 10.1: секреты перенесены в macOS Keychain; реальные значения удалены из файла.
