# Настройка Telegram-бота LogistAI через BotFather

Полный чек-лист: от создания бота до подключения к приложению.
Секреты живут только в Keychain — токен в файлы и чат не вставляется.

## 1. Создать бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. **Name** (отображаемое имя): `LogistAI — диспетчер грузов`
3. **Username**: любой свободный, оканчивается на `bot`, например `logistai_dispatcher_bot`.
4. BotFather вернёт **токен** вида `123456789:AA…` — сразу сохраните его в
   Keychain (экран настроек LogistAI → Telegram → Bot Token). Никому не
   пересылайте и не вставляйте в файлы.

## 2. Список команд (`/setcommands`)

Отправьте BotFather `/setcommands`, выберите бота и вставьте:

```
start - что умеет LogistAI
help - список команд
status - состояние ATI и платформы
search - запустить поиск грузов сейчас
report - дневная сводка аналитики
settings - текущие настройки (read-only)
```

## 3. Описание бота (`/setdescription`)

Рекомендуемый текст (показывается до нажатия Start):

```
LogistAI — AI-диспетчер грузов. Слежу за ATI, считаю экономику каждого рейса
(топливо, платные дороги, холостой пробег) и присылаю только те грузы,
которые реально выгодны вашей машине. Команды: /status, /search, /report.
```

## 4. About (`/setabouttext`)

Короткий текст для профиля (до 120 символов):

```
AI-диспетчер грузов: подбор по прибыли, уведомления о лучших рейсах.
```

## 5. Картинка профиля (`/setuserpic`)

Загрузите иконку LogistAI (грузовик на светлом фоне, 512×512).

## 6. Приватность (`/setprivacy`)

Оставьте **Enabled** (по умолчанию): бот работает в личном чате с вами и
не должен читать чужие групповые сообщения. LogistAI дополнительно отвечает
ТОЛЬКО настроенному Chat ID — сообщения из других чатов игнорируются.

## 7. Подключение к LogistAI

1. Напишите боту `/start` (иначе Telegram не даст ему писать вам).
2. Узнайте свой Chat ID: напишите [@userinfobot](https://t.me/userinfobot)
   или посмотрите поле `chat.id` в getUpdates.
3. В LogistAI: Настройки → Telegram → вставьте токен (уйдёт в Keychain)
   и Chat ID → «Проверить» (getMe → getChat → тестовое сообщение).

## 8. Что умеет бот

| Команда | Что делает |
|---|---|
| `/start`, `/help` | приветствие и список команд |
| `/status` | Authentication, Market access, доступные площадки, полученные грузы, Telegram, Scheduler |
| `/search` | немедленный опрос ATI через Scheduler (CommandBus → RunJobNow) + итог |
| `/report` | сводка аналитики: найдено, подходящих, средняя прибыль, лучший маршрут, доход, ошибки |
| `/settings` | машина, регион, минимальная ставка, веса AI Score, источники, каналы (read-only) |

Уведомление о лучшем грузе приходит с кнопками:
**Открыть ATI** (только подтверждённая ссылка на конкретную карточку ATI) ·
**Открыть поиск ATI** (общая страница поиска, если карточку построить нельзя) ·
**Подробнее** (полная карточка) · **Игнорировать** (убирает груз из рекомендаций).

## 9. Безопасность

- Токен и Chat ID никогда не пишутся в логи (санитизация в клиенте).
- Бот отвечает только настроенному Chat ID; чужие чаты игнорируются.
- `callback_data` кнопок проходит whitelist-валидацию.
- Все пользовательские данные экранируются в HTML-разметке.
- Сообщения длиннее 4096 символов разбиваются автоматически.
