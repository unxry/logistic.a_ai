# LogistAI Design System v2

> Единственный источник визуальных решений. Код токенов — `app/ui/theme/tokens.py`
> (значения здесь и там охраняются тестом). Новый экран начинается с этого файла,
> а не с копирования QSS соседней страницы.
>
> v2 (Stage 9.8): две полноценные палитры Light/Dark, три уровня тени
> REST/HOVER/ACTIVE, каскадные появления, «живые» окончания графиков,
> sheet-модалки и Raycast-палитра.

## 0. Характер продукта

LogistAI — **AI-диспетчер грузов**. Ощущение: спокойный, дорогой инструмент,
внутри которого непрерывно работает умный помощник. Ориентиры: Apple
Intelligence, Linear, Raycast, Arc. Следствия:

- интерфейс **тихий**: цвет появляется только там, где есть смысл (статусы, деньги, действие);
- «жизнь» показывается **микродвижением** (пульс индикатора, count-up цифр, materialize карточек), а не мигающими баннерами;
- плотность умеренная: воздух дороже ещё одной метрики;
- всё объяснимо: у каждого вывода AI есть панель «почему» (explanation из движка, не выдумка UI).

Технически «стекло» — эмуляция через QSS-токены (полупрозрачный белый + мягкая
тень + тонкая граница); нативный NSVisualEffectView подключается при упаковке
(ADR-0002), токены не меняются.

## 1. Цвет

Две ПОЛНОЦЕННЫЕ палитры (не инверсия): поверхности и текст задаются отдельно
для Light и Dark, акценты Apple общие. `tokens.apply_theme("light"|"dark")`
вызывается composition root'ом из настроек ДО сборки окна; живое переключение
без перезапуска и режим System — вместе с формами настроек (Stage 9.1).

### 1.3 Акценты (общие для обеих тем)

| Токен | Значение | Использование |
|---|---|---|
| `BLUE` | `#0A84FF` | ЕДИНСТВЕННЫЙ цвет действия (кнопки, ссылки, выбранный пункт) |
| `GREEN` | `#30D158` | успех, деньги «в плюс», online |
| `ORANGE` | `#FF9F0A` | предупреждение, degraded |
| `RED` | `#FF453A` | ошибка, недоступность |
| `MUTED` | `#8E8E93` | выключенное/неизвестное |

Тонировки состояний: `tint(color) = color @ 12%` — фон бейджей и чипов; текст
чипа — сам цвет. **Запрещено:** кислотные оттенки, градиенты в качестве фона
карточек (градиент допустим только как заливка ПОД линией графика ≤12% альфы и
в glow ScoreRing), более одного акцентного цвета в одном блоке.

Semantic-маппинг: `BadgeTone.OK→GREEN, WARNING→ORANGE, ERROR→RED, MUTED→MUTED`.
Прибыль > 0 — всегда `GREEN`; убыток — `RED`; цена — `TEXT`.

## 2. Типографика

Шрифтовой стек: `.AppleSystemUIFont, SF Pro Text, SF Pro Display, Helvetica
Neue, Inter, Segoe UI, Noto Sans` (на macOS получается системный San Francisco).

| Роль | Размер/вес | Использование |
|---|---|---|
| `DISPLAY` | 30 / 700 | деньги в Hero, главная цифра MetricCard |
| `TITLE` | 21 / 700 | заголовок страницы |
| `HEADLINE` | 15 / 600 | заголовок карточки, маршрут груза |
| `BODY` | 13 / 400 | основной текст |
| `CAPTION` | 11 / 500, letter-spacing +0.6px, UPPERCASE | подписи секций («ЛУЧШИЙ ГРУЗ СЕГОДНЯ») |
| `MICRO` | 11 / 400 | время, метаданные |

Правила: не более двух весов в одной карточке; деньги никогда не мельче BODY;
UPPERCASE только для CAPTION.

## 3. Сетка, размеры, радиусы

- Базовая сетка **4pt**: отступы 4, 8, 12, 16, 20, 24, 32, 40.
- Внутренний паддинг карточки: **20**; между карточками: **16**; поля страницы: **24**.
- Сайдбар: ширина **224**, пункт 36 высотой, радиус пилюли 9.
- Радиусы: чип/бейдж **8**, контрол (кнопка, поле) **10**, карточка **16**, hero/оверлей **20**.
- Кнопки: высота 36 (обычная) / 30 (компактная); икон-кнопка 28×28.
- Минимальный размер окна 1080×700; целевой 1280×800.

## 4. Глубина (тени)

Три состояния интерактивной поверхности + glow, всегда через
`QGraphicsDropShadowEffect`:

| Уровень | Параметры | Кому |
|---|---|---|
| `RESTING` | blur 28, y 8, `rgba(16,24,40,0.10)` | карточки в покое |
| `LIFTED` (hover) | blur 44, y 16, `rgba(16,24,40,0.18)` | карточка под курсором, открытый оверлей |
| `ACTIVE` (нажатие) | blur 18, y 4, `rgba(16,24,40,0.14)` | карточка в момент клика («прижата») |
| `GLOW_BLUE` | blur 36, y 0, `rgba(10,132,255,0.35)` | ТОЛЬКО ScoreRing и активный AI-индикатор |

В тёмной теме те же формы, но чёрная тень с альфой ×1.8 (свет забирает
меньше — глубину даёт плотность). Подъём сопровождается подсветкой фона
CARD → CARD_HOVER и рамкой `rgba(10,132,255,0.35)` — только у
интерактивных карточек; геометрия НИКОГДА не меняется (ничего не прыгает).

## 5. Движение

| Токен | Значение | Использование |
|---|---|---|
| `FAST` | 140 ms, OutCubic | hover, смена цвета |
| `BASE` | 220 ms, OutCubic | подъём тени, появление действий |
| `ENTER` | 320 ms, OutCubic | materialize карточки |
| `COUNT` | 650 ms, OutCubic | count-up денег и счётчиков |
| `PULSE` | 1600 ms, loop | ореол StatusIndicator |

Паттерны (реализованы в `theme/motion.py`):
- **materialize** — появление новой карточки: opacity 0→1 + «рост» 0.96→1
  (анимация внутренних полей обёртки — layout не прыгает);
- **count-up** — деньги/счётчики набегают за COUNT; форматирование — из
  viewmodels (`120 000 ₽`);
- **lift** — тень RESTING→LIFTED + подсветка фона на hover; нажатие —
  RESTING→ACTIVE за FAST;
- **pulse / breathing** — расходящийся ореол статуса и «дыхание» конечных
  точек графиков (цикл 0→1→0, InOutSine); только пока виджет видим;
- **cascade** — каскад секций страницы: каждая следующая проявляется со
  сдвигом 30–60 ms (Dashboard: Hero → метрики → рекомендации → источники →
  активность → машина);
- **enter_page** — переход раздела: fade + «подъезд» контента снизу на 12 px;
- **sheet** — модалка выезжает сверху на 26 px с fade (macOS sheet);
  палитра открывается scale 0.98→1 + opacity;
- **reveal scrollbar** — скроллбар-невидимка: прозрачен в покое, проявляется
  на время прокрутки (динамическое свойство `revealed` + linger 900 ms).

Правила: никакого движения дольше 400 ms (кроме пульса/счёта); одновременно
анимируется одна доминанта (каскад — это ОДНА волна, не салют); все анимации
прерываемы (повторный hover не ждёт конца прошлой); бесконечные циклы
останавливаются в hideEvent — скрытый виджет не жжёт кадры.

## 7. Голос интерфейса

Русский, коротко, без канцелярита. Пустые состояния объясняют, ЧТО произойдёт
(«AI начнёт искать грузы, как только подключится первый источник»), ошибки —
что делать дальше. Деньги всегда с ₽ и пробельными разрядами (формат приходит
из viewmodels — UI не форматирует деньги сам).

## 8. Доступность и производительность

- Контраст текста на карточках ≥ 4.5:1 (TEXT на CARD = 12.6:1; SECONDARY = 4.6:1).
- Смысл никогда не кодируется только цветом: статус = цвет + подпись.
- Фокус клавиатуры видим (кольцо BLUE 2px); палитра и модалки управляются с клавиатуры.
- Анимации — только transform/opacity-эквиваленты (тень/поля/прозрачность), без relayout тяжёлых списков; пульс останавливается у скрытых виджетов.

## 9. Чего не делать

- Второй синий/новый акцент «для красоты».
- Таблицы там, где решение принимает человек, — карточки.
- Тени темнее LIFTED, границы темнее BORDER.
- Анимация ради анимации: если движение не сообщает смену состояния — его нет.
- Форматировать данные в виджетах: все строки приходят из `app/ui/viewmodels`.
