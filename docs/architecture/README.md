# Архитектурная документация

Основной документ — [ARCHITECTURE.md](../../ARCHITECTURE.md) в корне репозитория:
слои, матрица импортов, механизмы, рецепты расширения, запреты.

Обоснования решений — в [ADR](../adr/).

В этом каталоге накапливаются дополнительные материалы: диаграммы (C4, sequence),
описания подсистем, заметки по производительности. Диаграммы храним в исходном
виде (mermaid/PlantUML в .md), а не картинками.
